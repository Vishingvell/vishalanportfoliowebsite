# Repository instructions

- Keep all personal information in `src/content/portfolio.ts`.
- Never invent portfolio content or infer missing claims.
- Do not publicly render incomplete entries; update `CONTENT_NEEDED.md` instead.
- Keep TypeScript strict mode enabled.
- Prefer React Server Components and keep client components minimal.
- Run lint, type checking and a production build after meaningful changes.
- Maintain semantic HTML, keyboard access, visible focus states and reduced-motion support.
- Preserve the sunset Ink & Wash visual system through the CSS variables in `app/globals.css`.
- Avoid unnecessary production dependencies, server functions, databases and APIs.
- Do not add tracking, analytics or cookies without explicit approval.
- Keep external links safe with `rel="noopener noreferrer"`.
- Update `CONTENT_NEEDED.md` whenever missing information is discovered.
